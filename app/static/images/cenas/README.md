# Cenas dos desenhos

Salve aqui o print do episódio de cada receita. O site usa o arquivo
automaticamente (não precisa reiniciar). Sem arquivo, o card mostra um fundo
colorido com o emoji do desenho.

Nome do arquivo = título da receita sem acentos, em minúsculas, com hífens.
Formatos aceitos: `.jpg`, `.jpeg`, `.png`, `.webp`. Proporção ideal 16:10
(por exemplo 1280x800).

| Receita | Arquivo |
|---|---|
| Hambúrguer de Siri | `hamburguer-de-siri.jpg` |
| Cachorro-quente Krusty | `cachorro-quente-krusty.jpg` |
| Donut Rosa do Homer | `donut-rosa-do-homer.jpg` |
| Ramen Ichiraku Caseiro | `ramen-ichiraku-caseiro.jpg` |
| Panqueca de Bacon do Finn e Jake | `panqueca-de-bacon-do-finn-e-jake.jpg` |

Receitas novas seguem a mesma regra: "Pizza do Chaves" vira `pizza-do-chaves.jpg`.
