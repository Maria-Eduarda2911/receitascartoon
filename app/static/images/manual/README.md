# Imagens manuais

Coloque aqui os arquivos de imagem que você quiser usar no catálogo.

- Nome do padrão esperado: `nome-da-receita.ext`
- O app referencia os arquivos em `app/static/images/...`
- Os caminhos usados pelo site são do tipo `/static/images/nome-da-receita.svg`

Se quiser substituir alguma imagem do catálogo, mantenha o mesmo nome do asset correspondente e reinicie o app.
